├─ Abra: https://app.supabase.com
├─ Vá para: SQL Editor → New Query

├─ Cole e clique: Execute
└─ Pronto! Tabela criada

PASSO 2: RECARREGAR O APP
├─ Abra o navegador
├─ Clique em "Bloqueados" na navegação
├─ Você verá a aba vazia (pronta para usar)
└─ Pronto!

PASSO 3: USAR
├─ Clique: "Adicionar à blacklist"
├─ Preencha: Telefone (obrigatório) + Nome + Motivo
├─ Clique: "Adicionar à blacklist"
├─ Pronto! Lead está bloqueado
└─ Ele não receberá mensagens em disparos futuros

📊 BANCO DE DADOS

Tabela: blacklist
Campos:
  - id (UUID) - Identificador único
  - telefone (VARCHAR) - Número (UNIQUE)
  - nome (VARCHAR) - Nome do lead (opcional)
  - motivo (TEXT) - Razão do bloqueio
  - data_bloqueio (TIMESTAMP) - Quando foi bloqueado
  - adicionado_por (VARCHAR) - Quem adicionou
  - created_at (TIMESTAMP) - Criação
  - updated_at (TIMESTAMP) - Última atualização
